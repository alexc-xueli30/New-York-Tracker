## Components

### Pin Markers
- Source: Lucide React icons — `CircleDot` (pothole), `Landmark` (playground), `Droplet` (water), `Leaf` (tree), `Star` (other)
- Style: outlined, flat fill (severity tier color), no drop shadow, stroke-width 2px, black 3px outer ring via SVG wrapper
- Size varies by severity tier (see above)
- On hover/focus: scale 1.1, cursor pointer

### DetailCard
- Surface: `#1A1A2E`, border: 2px solid `#F5F5F0`
- Optional: halftone dot pattern at 15% opacity as background texture
- Framer Motion: slides up from bottom, spring `{ stiffness: 400, damping: 10 }`
- On mobile: bottom sheet, 80% screen height, swipe-down or X button to dismiss
- On desktop: side panel (right), 360px wide
- Severity badge: Bangers font, tier color background, black text, 2px black border

### Vote Buttons (Like/Dislike)
- 44px touch target minimum
- On vote: button bg fills (like=#4ECDC4, dislike=#FF6B35), count does spring scale bounce `{ stiffness: 400, damping: 10 }`
- Active state persists (stored in localStorage for dedup)
- Real-time count from Supabase subscription

### Stats Strip
- IBM Plex Mono, `text-sm`
- 3-4 pills separated by `·` midpoint
- Background: `#1A1A2E`, top and bottom border: 1px solid `#F5F5F0`
- On mobile: compress to abbreviations (847 · 4.2d · 71%)

### Ticker (desktop only)
- Continuous horizontal scroll, ~40px/s
- IBM Plex Mono, `text-sm`, `#F5F5F0` on `#0D0D0D`
- Prefix: "RECENT FIXES:" in Bangers
- Pause on hover

### Spotted Feed
- List layout, not card grid
- Each entry: TikTok thumbnail (oEmbed), title (Inter bold), category tag, link-out arrow
- On mobile: ticker appears here above the list

## Animation Specs

All Framer Motion springs unless noted:
- DetailCard entrance: `{ stiffness: 400, damping: 10 }`
- Vote count bounce: `{ stiffness: 400, damping: 10 }` (same spring family)
- Pin hover scale: CSS `transition: transform 150ms ease`
- Ticker: CSS `animation: ticker-scroll linear infinite`

## Halftone Texture

- Applied to: header background, DetailCard background (at 15% opacity)
- Implementation: CSS `radial-gradient` — `background-image: radial-gradient(circle, #F5F5F0 1px, transparent 1px); background-size: 8px 8px; opacity: 0.15;`
- NOT applied to: map canvas, stats strip, body backgrounds

## Empty States

- **Map scanner offline** (AI curation failed): "SCANNER OFFLINE — Check back shortly" in Bangers, halftone static TV texture behind map
- **No votes yet**: Like/dislike buttons show "—" count, not "0"
- **Spotted feed empty**: "NOTHING SPOTTED YET" in Bangers, brief instruction

## Accessibility

- Touch targets: 44px minimum (vote buttons, pin markers, nav tabs)
- Color contrast: `#F5F5F0` on `#0D0D0D` = 19.3:1 (AAA). `#FFE600` on `#0D0D0D` = 12.9:1 (AAA)
- ARIA: map container has `role="application"` + `aria-label="NYC Fix sightings map"`. Detail card is `role="dialog"` with focus trap
- Keyboard: Tab navigates pins (in source order), Enter opens detail card, Escape closes
- Screen reader: each pin has `aria-label="[Category]: [Title], severity [CRITICAL/HIGH/NOTABLE]"`
